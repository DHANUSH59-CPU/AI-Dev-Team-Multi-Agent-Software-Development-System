🔁Dev Loop — The Self-Healing Factory

The question you WILL get: "what happens when generated code fails?" — this picture is the answer.

🧲 MNEMONIC — DEV LOOP STEPS "Some Coders Can Really Execute Snapshots" = Select → Context → Code → Review → Execute → Snapshot
🧲 MNEMONIC — DEBUGGER TIERS "Little Bugs Require Humans" = Local fix → Broader context → Rollback snapshot → Human escalation

🧩 Context Builder = mini-RAG

Before coding, fetches what the file needs via 3-tier lookup: exact match (dict, O(1)) → fuzzy match → regex scan of disk. Zero tokens. Say "this is retrieval-augmented generation" — interviewers love it.

⌨️ Why ONE file per LLM call?

Big outputs get truncated mid-JSON. Small focused calls = complete files, fewer retries, cheaper. Trade-off: more calls, but each one is reliable.

📸 Snapshot = git for state

After each success, copy.deepcopy(state) stored like a stack. Failure later? pop() → instant rollback. Stack data structure in action.

✂️ Simplify = divide & conquer

Rejected 3×? Task is too big — split into sub-tasks and retry each. Classic divide-and-conquer applied to AI workflows.

🃏Flashcards — Hover To Flip

Active recall — try answering BEFORE flipping. That's how memory forms.

🕸️

Why LangGraph instead of plain Python functions?

hover to flip ↻

27 nodes need: shared state, conditional routing, loops, checkpointing. Plain functions = spaghetti. LangGraph forces nodes to talk ONLY through state with reducers → predictable, debuggable, resumable.

🧬

What are reducers? Name all 3.

hover to flip ↻

Rules for merging new state values:
① last-write — overwrite (currentTask)
② merge_objects — {**old, **new} (blueprint)
③ accumulate — append list (conversation, fileRegistry)
Nodes stay pure functions: state in → state out.

📸

Why checkpoint to Redis after EVERY node?

hover to flip ↻

Runs take 30–60 min, 100+ API calls. Crash at node 20 without checkpoints = restart from zero = wasted money. With Redis: resume exactly at node 20. Fallback: in-memory checkpointer if Redis is down.

🐳

Why Docker for running generated code?

hover to flip ↻

LLM code is untrusted — could delete files or eat resources. Docker = OS-level isolation ("the glass room"). Python docker SDK: create containers, bind-mount project folder, docker exec tests, cleanup.

🌉

How does human-in-the-loop work without blocking? (InputBridge)

hover to flip ↻

Agent emits a WebSocket event → awaits asyncio.Future(). User answers in dashboard → WS handler calls future.set_result(answer) → agent resumes. Event loop never blocks.

💸

3 ways you control LLM cost?

hover to flip ↻

① Hard budget — raise exception before call if ≥ $2
② 15 of 27 nodes are token-free — pure Python clerks
③ One file per call — no truncation → no wasted retries

✅

Why is the Blueprint Validator pure Python (no LLM)?

hover to flip ↻

Validation needs guarantees, LLMs hallucinate. 5 checks: routes→real tables, valid foreign keys, no orphan tables, consistent auth, consistent naming. Deterministic, instant, $0.

🧠

How is contextBuilder a form of RAG?

hover to flip ↻

RAG = retrieve relevant docs, inject into prompt. contextBuilder retrieves existing files from the registry before the coder writes → LLM uses real import names & patterns instead of hallucinating them.

🗂️

Name 4 data structures used & where.

hover to flip ↻

① Queue — task queue (FIFO)
② Stack — snapshots (push/pop rollback)
③ HashMap — file registry O(1) lookup
④ DAG — LangGraph itself (nodes + directed edges)

⚙️

Process vs Thread vs Coroutine — which did you pick & why?

hover to flip ↻

Coroutines (asyncio) — workload is I/O-bound (waiting on Gemini, Redis, Docker), not CPU-bound. One thread handles 100+ concurrent I/O ops, switching at await. Threads hit the GIL; processes are overkill.

📦

deepcopy vs shallow copy — where is each used?

hover to flip ↻

Shallow — merge_objects reducer: {**old, **new} (fast, fine for fresh values).
Deep — copy.deepcopy(state) for snapshots: rollback points MUST be independent or later edits corrupt them.

🤹

Why multi-agent instead of one giant LLM call?

hover to flip ↻

① Context window can't hold 25 files + history
② Errors compound in long chains
③ Specialists beat generalists — focused short prompts (PM/architect/coder/reviewer) are far more reliable.

🎤The 60-Second Pitch

Practice until you can say it while drawing the architecture at the same time.

"I built a Python-based autonomous AI development system with 27 specialized agents orchestrated by LangGraph. You type a requirement like 'build a todo app' — the PM agent clarifies the spec, the Architect designs the database and APIs in 5 steps, the Planner creates 21 tasks and spins up Docker containers, then a self-healing Dev Loop writes every file with Gemini 2.5 Flash, has a Reviewer approve it, tests it in Docker, and on failure a 3-tier Debugger escalates from auto-fix to rollback to human. Redis checkpoints state after every node for crash recovery. Total cost: about 13 cents per app."

😈 "What was the hardest bug?"

LLM JSON truncation — Gemini cut off mid-JSON. Built a repair pipeline: detect MAX_TOKENS, close unclosed brackets/strings, retry. Then prevented it permanently with one-file-per-call.

🚀 "What would you improve?"

① Vector DB for semantic context retrieval (proper RAG) ② Parallel task execution within a phase ③ Support multiple LLM providers with automatic failover.

⚖️ "Biggest design trade-off?"

One-file-per-call: more API calls but zero truncation. Checkpoint-every-node: Redis overhead but crash-proof. Code validators over LLM: only structural checks but 100% deterministic.

🤝 "Tell me about teamwork." (sneaky one)

"My agents ARE a team — each has ONE responsibility and they communicate only through shared state, never direct calls. That's how I think real teams should work too: clear interfaces, no tight coupling."
